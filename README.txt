САЙТ «БАТЫРХАН + НАЗЕРКЕ» — ИНСТРУКЦИЯ
========================================

СТРУКТУРА ФАЙЛОВ
----------------
index.html       — главная страница (фото + таймер + дата начала)
history.html     — страница «История»
nicknames.html    — страница «Как они себя называют»
photos.html      — страница «Фотографии»
style.css        — все стили (цвета, шрифты, вёрстка)
script.js        — таймер и разбросанные по сайту слова-обращения
photos/          — папка с фотографиями (сейчас там заглушки)

КАК ОТКРЫТЬ В VS CODE
----------------------
1. Распакуй архив в любую папку.
2. Открой эту папку в VS Code (File → Open Folder).
3. Установи расширение "Live Server" (если ещё не стоит) и нажми
   "Go Live" внизу справа, либо просто открой index.html в браузере
   двойным кликом — сайт полностью статический, сервер не обязателен.

КАК ВСТАВИТЬ СВОИ ФОТО
-----------------------
В папке photos/ лежат заглушки:
  hero.jpg   — большое фото на главной странице
  photo1.jpg … photo6.jpg — фото в галерее

Просто замени эти файлы своими, сохранив ТЕ ЖЕ имена — и всё
подхватится автоматически. Если хочешь добавить больше 6 фото в
галерею, открой photos.html и скопируй строку:

  <figure><img src="photos/photo7.jpg" alt="..."></figure>

добавив новый файл photo7.jpg в папку photos/.

КАК ПОМЕНЯТЬ ДАТУ НАЧАЛА ОТНОШЕНИЙ
------------------------------------
Открой script.js и поменяй строку:

  const START_DATE = new Date("2025-10-03T00:00:00");

Таймер на главной странице считает года/месяцы/дни/часы/минуты/секунды
от этой даты и обновляется каждую секунду — сайт всегда будет
показывать актуальное время вместе, сколько бы вы его ни открывали.

КАК ПОМЕНЯТЬ ЦВЕТА
-------------------
Все цвета собраны в самом верху style.css в блоке :root — там уже
стоит нежно-розовый (#ebccc7) и бордовый (#6d1b2b), как ты просил.
Меняй значения там — они применятся сразу везде на сайте.

КАК ПОМЕНЯТЬ ТЕКСТ ИСТОРИИ / ОБРАЩЕНИЯ
-----------------------------------------
history.html   — каждая встреча оформлена как <li> внутри <ol class="timeline">
nicknames.html — каждое слово — это <span> внутри <div class="nick-grid">

Просто редактируй текст внутри тегов, HTML-разметку менять не нужно.
